From topic signals to accountable publication

Satellite Publisher is a sanitised demonstration of a multi-site editorial workflow. It connects discovery, scoring, planning, independent generation, human review and controlled publishing — without treating RSS articles as source copy.

Capabilities

Discovery agent

Reads public RSS or sitemap signals, normalises URLs and avoids duplicate topics.

Editorial planning

Routes a topic to a destination profile and builds a structured draft hand-off.

Multi-site adapters

Supports FTP and WordPress bridge patterns after explicit approval.

Human-in-the-loop by design

Originality safeguards

Only short source excerpts are allowed into the public workflow. Drafts carry a no-copy instruction and are checked for excessive overlap.

Dry-run by default

DRY_RUN=true blocks FTP, WordPress and Google Indexing calls. The demo writes previews and logs locally.

OpenAI implementation

OpenAI Responses API with gpt-5.6-terra supports planning, drafting and review. OpenAI Images API with gpt-image-2 supports images.

Public RSS feeds are used only as topic-discovery signals. Satellite Publisher does not republish source articles. A human editor remains responsible for factual validation, editorial judgement and production decisions.

A transparent technical demonstration

Codex was used as the primary coding agent throughout architecture, implementation, refactoring, debugging, workflow orchestration, documentation and deployment preparation. Cédric Martin retains human oversight over product goals, editorial rules and publication decisions.
